# 小T翻译 (XiaoT Translate)

[English](README.md) | 中文文档

一个面向**学术 PDF 翻译**的 Chrome 扩展：双语对照阅读、多引擎翻译、AI 文档对话、语音合成导出。

## 功能

- **PDF 文档翻译** —— 本地/在线 PDF 一键翻译为双语对照视图，支持译文叠层、划词与批注
- **划词翻译** —— PDF 阅读器内选中文本，`Ctrl+C` 后按 `Alt+T` 经剪贴板翻译
- **多翻译引擎** —— 百度、火山引擎、腾讯、云端 DeepSeek（Pro）、自定义 OpenAI 兼容模型（1~3 槽位）、本地模型（如 Ollama）
- **AI 文档对话** —— 云端 DeepSeek（Pro）/ 自定义 / 本地模型，对文档内容提问
- **段落级缓存** —— 本地缓存 + 云端公共池，重复段落不再重复翻译
- **翻译历史** —— 本地记录，可选云端同步（Supabase 账户）
- **语音合成导出** —— 百度 TTS / 自定义 OpenAI 兼容 `/v1/audio/speech` 接口 / 本地 [CosyVoice2-0.5B](https://github.com/FunAudioLLM/CosyVoice) 服务一键预设
- **分享译文** —— 导出 HTML 或长图
- **统一设置页** —— 全部引擎/模型配置集中编辑与测试，支持凭据复用
- **免费版与 Pro** —— 账户体系、配额与云端功能（Supabase + Cloudflare Worker）

## 安装

1. 下载或克隆本仓库
2. 打开 `chrome://extensions`，开启**开发者模式**
3. 点击**加载已解压的扩展程序**，选择仓库目录

## 开发

```bash
npm install
npm run lint   # ESLint
npm test       # Node 测试（169 项）
```

### 目录结构

| 路径 | 说明 |
|---|---|
| `manifest.json` | Chrome MV3 清单 |
| `lib/` | 核心模块：设置、翻译、TTS、缓存 |
| `options.html/js` | 统一设置页 |
| `doc-translate.html/js` | 文档翻译页（双语对照） |
| `background.js`, `content.js`, `popup.*`, `offscreen.*` | 扩展入口 |

> **云端后端不开源。** 上表本地功能仅凭本仓库即可完整使用（自备 API Key / 本地模型）；账户、Pro、云同步等功能依赖作者的线上服务，本地使用无需这些功能。

### 使用百度翻译

插件内置多种翻译引擎。你只需要填好想用的那家服务的密钥，翻译时选择它即可。

1. **准备密钥** —— 注册并登录[百度翻译开放平台](https://fanyi-api.baidu.com/)，申请「通用文本翻译」服务，创建一个应用，记下页面上的 **APPID** 和**密钥**。
2. **填写设置** —— 打开插件统一设置页（在插件弹窗中点击 **⚙️ 设置**）。在「翻译引擎」中选择「百度（APPID + 密钥）」，把 APPID 和密钥粘贴进去，配置会自动保存。
3. **确认可用** —— 点「测试翻译」，出现成功提示说明配置正确。
4. **开始使用** —— 回到插件弹窗，在翻译引擎中选择「百度」，之后翻译 PDF 或划词翻译都会使用百度。

小提示：百度免费版有调用频率限制，长文档翻译会稍慢一些，属于正常现象；密钥只保存在本机，不会上传。

如果你使用的服务商提供 OpenAI 兼容接口，也可以直接选择「自定义模型」，无需等待单独适配，详见下方[「使用自定义翻译模型」](#使用自定义翻译模型openai-兼容)小节。

### 使用自定义翻译模型（OpenAI 兼容）

任何提供 OpenAI 兼容 `/chat/completions` 接口的服务都可以用作翻译引擎，包括 Ollama、llama.cpp、vLLM 等本地部署的模型。

1. **选择引擎** —— 在统一设置页「翻译引擎」中选择「自定义模型（OpenAI 兼容）」。最多可配 3 个槽位，各自独立保存，也可以只配 1 个。
2. **填写槽位** —— 每个槽位四项：
   - **接口地址**：填到 `/v1` 这一级（如 `https://api.example.com/v1`），`/chat/completions` 由扩展自动拼接；本地 Ollama 填 `http://localhost:11434/v1`。
   - **API Key**：服务商的密钥；本地服务可留空。
   - **模型名**：如 `deepseek-chat`、Ollama 中的 `llama3` 等。
   - **字节上限**：500~200000，控制长文档的分块大小，留空用默认值。
3. **确认可用** —— 每个槽位有独立「测试」按钮；区域底部「测试翻译」会用当前编辑的槽位试翻一句。
4. **开始使用** —— 在插件弹窗的翻译引擎中选择「自定义模型」，槽位也在弹窗中切换；之后 PDF 翻译和划词翻译都会使用它。

小提示：扩展会自动附带完整翻译指令（含目标语言），通用对话模型与翻译专用模型都能直接使用。本地 Ollama 需要先设置环境变量 `OLLAMA_ORIGINS=chrome-extension://*` 并重启，否则扩展的跨域请求会被拒绝（扩展会提示 403）。

### 使用自定义 AI 分析模型

AI 文档对话与全文分析总结可以使用任意 OpenAI 兼容 `/chat/completions` 接口；云端模型（Pro）免配置。

1. **填写设置** —— 在统一设置页「AI 分析」中选择「自定义模型（自带密钥）」，同样最多 3 个槽位（接口地址 / API Key / 模型名 / 字节上限），每个槽位有独立「测试」按钮，底部「测试对话」可试聊一句。
2. **切换引擎** —— 实际使用云端还是自定义模型，在文档翻译页的「🤖 AI 分析」窗口中选择；免费/未登录用户自动使用自定义模型。
3. **调整上下文** —— 这里的字节上限同时决定送入模型的文档上下文长度（留空默认 40000 字符，最大 60000）。本地小显存模型建议按模型上下文窗口适当调小，避免长文档超出上下文报错。

### 使用百度语音合成

「🎧 导出音频」可以把译文合成为 MP3，方便离线收听或分享。

1. **准备密钥** —— 登录百度智能云语音技术控制台，创建应用，记下 **API Key** 和 **Secret Key**。注意：语音合成的密钥与百度翻译的密钥不是同一套。
2. **填写设置** —— 在统一设置页的「语音合成」中，把来源选为「百度（自带密钥）」，填入 API Key 和 Secret Key，并按喜好选择音色和语速，配置会自动保存。
3. **确认可用** —— 点「测试合成」试听，能正常播放即配置成功。
4. **导出音频** —— 打开文档翻译页，译文生成后点「🎧 导出音频」，在弹窗中选择「百度（自带密钥）」，再点「生成并下载」即可得到 MP3 文件。

小提示：长文档会按段落分批合成再拼接成一个文件，需要等待一会儿；也可以在弹窗中切换为「自定义接口」，改用其他兼容 OpenAI 语音接口的服务。

### 使用自定义语音合成接口

语音合成支持任意 OpenAI 兼容的 `/audio/speech` 接口。

1. **选择来源** —— 在统一设置页「语音合成」中把来源选为「自定义接口」。设置页所选来源即导出音频实际使用的来源，也可以在导出弹窗内临时切换。
2. **填写设置** —— 四项：
   - **接口地址**：完整 URL，如 `https://api.openai.com/v1/audio/speech`；本机 `127.0.0.1` / `localhost` 端点无需 API Key。
   - **API Key**：服务商密钥，本地服务可留空。
   - **模型名**：如 `tts-1`，按服务商实际支持填写。
   - **音色**：OpenAI 标准音色（alloy / echo / fable / onyx / nova / shimmer）下拉选择，或选「自定义…」填入服务商支持的音色名。
3. **确认可用** —— 点「测试合成」试听，能正常播放即配置成功。

小提示：合成请求体为 OpenAI 标准形态（`model` / `input` / `voice` / `response_format: mp3`），长文档会按段落分批合成再拼接为一个 MP3。

### 使用本地 CosyVoice2 服务

本地部署 [CosyVoice2-0.5B](https://github.com/FunAudioLLM/CosyVoice)，暴露 OpenAI 兼容的 `/v1/audio/speech` 端点后，在设置页点**「填入本地 CosyVoice2」**按钮一键完成配置。本机 `127.0.0.1` 端点无需 API Key。
